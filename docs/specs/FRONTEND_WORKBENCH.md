# 前端风格与工作台交互

决策整理日期：2026-10-22。依据用户已确定并实施的前端方案、首页可关闭及删除“输出”页签的决定，固定后续开发应遵守的界面规则。本文记录设计与行为要求；实现差距、复现脚本、截图和各轮测试结果保存在 `docs/AgentDocs/`，不能用规格存在代替功能验收。

内置插件位置以 [WP-001–009](WORKBENCH_PLACEMENT.md) 为准，编辑命令以 [ED 规格](EDITING_COMMANDS.md) 为准，导入与任务语义分别以 [IC](IMPORT_CORE.md)、[IP](IMPORT_PROTOCOL.md)、[LW](LCSC_IMPORT_WORKFLOW.md) 为准。本文件不改变这些契约。

## 视觉基线

| 编号 | 稳定规则 |
| --- | --- |

| FW-003 | 普通界面使用现有系统 UI 字体栈，基准正文为 13px；路径、OID 与代码差异使用等宽字体。名称和主动作优先，次要元数据弱化；长内容可截断展示，但应能在详情、提示或展开区域读取。 |

## 区域职责

| 区域 | 职责与边界 |
| --- | --- |

| 最左活动栏 | 切换工作空间导航、LCSC、Git 等主侧栏视图，保留设置入口。 |
| 主侧栏 | 工作空间、全部元件/问题/类型/子库导航，或当前插件的完整业务面板。 |
| 中心区 | 全部元件、设置、类型管理、匹配配置及第三方 `app.view`；页签、面包屑与分组负责页面导航。 |

| 状态栏 | 当前结果、选择、任务/问题及全库统计的简要反馈；不放长业务结果和插件表单。 |

| 编号 | 稳定规则 |
| --- | --- |
| FW-006 | 页面状态、业务模型与容器状态分离：工作台持有区域尺寸/显隐与页面身份，业务模型持有查询、草稿、结果和任务。普通切侧栏、关页签、隐藏面板不能重复提交写入或隐式撤销操作。 |
| FW-007 | **目前的内置插件 LCSC、Git 只放在最左边的侧边栏里**，即活动栏及其相邻主侧栏；完整操作遵守 WP-001–009，不增加中心详情页、右侧替代流程或工具栏重复入口。第三方插件通用 `app.view` 能力继续保留。 |
| FW-008 | 不恢复通用“输出”页签、原始 JSON 结果选择器或换名后的等价结果窗口。Git 差异/历史及 LCSC 导入结果归各自左侧面板；通用任务错误与诊断摘要归底部。若以后确有独立日志需求，应先定义用户任务、数据来源和容量，再单独修改决策。 |

## 尺寸、适配与恢复

以下为当前桌面布局基准，单位为 CSS px；用户拖动后的合法尺寸优先于默认值。默认底部面板隐藏，首次无配置时中心打开“全部元件”。

| 区域 | 默认尺寸 | 当前允许范围 |
| --- | --- | --- |
| 顶栏高 / 活动栏宽 | `48 / 48` | 保持当前紧凑基准，兼顾系统缩放 |
| 主侧栏宽 | `280` | `200–480` |
| 辅助侧栏宽 | `280` | `220–520` |
| 底部面板高 | `220` | `120–420` |
| 中心内容 | 最小宽 `360`、最小高 `240` | 过窄时优先收敛周围面板 |

| 编号 | 稳定规则 |
| --- | --- |
| FW-009 | 在可用宽度不足时优先收起辅助侧栏，再收敛主侧栏；主侧栏无法并排容纳时使用左侧抽屉。高度不足时可临时隐藏底部面板。自动收敛不改写用户保存的显隐偏好和面板尺寸，窗口恢复后重新计算展示。 |
| FW-010 | 列表与插件适配以所在容器实际宽度为依据，允许面板内独立滚动；长路径、OID、消息与差异不能撑破工作台。抽屉提供关闭入口和 Escape，键盘焦点与浮层行为使用现有工作台机制。 |
| FW-011 | 布局沿用现有宿主配置和版本化解析/迁移机制。异步配置加载完成后再恢复，避免默认值抢先覆盖已存布局；有效字段保留，坏字段可恢复，保存失败有反馈。 |
| FW-012 | 旧底部 `activeViewId: output` 迁移为 `tasks`，不重置其余尺寸、页面或分组。旧 LCSC/Git 中心页按 WP 清理；其它有效页面、第三方贡献及关闭首页状态应保留。 |

## 中心页面与首页生命周期

| 编号 | 稳定规则 |
| --- | --- |
| FW-013 | “全部元件”是普通可关闭页签，不设永久首页。关闭仅隐藏视图，不删除元件、数据库或会话编辑历史，不取消后台任务；关闭状态可保存，重载后不强制补回。 |
| FW-014 | 首页按稳定页面身份单例打开。重复打开应聚焦已有页签及所在组；全部关闭后保留可用中心空态，提供“打开全部元件”按钮。工作空间、全部元件、问题、类型和子库等需要列表的导航入口应打开或聚焦该单例，再执行相应查询意图。 |
| FW-015 | 重开首页保留模型持有的业务状态，具体导航动作仍按自身语义更新筛选。“全部元件”入口清除类型/问题/目标子库筛选与对象选择，保留用户关键词；它与编辑菜单中的“全选”分别处理。 |
| FW-016 | 页签选择、关闭、返回、分组与拖移只管理页面身份；保留当前已实现的左右/上下分组及有界导航，不扩展为任意自由停靠。首页关闭或非活动时，不允许后台对象列表接收编辑命令；有效文本输入继续遵守 ED 上下文规则。 |

## 元件列表、数量与选择

| 编号 | 稳定规则 |
| --- | --- |
| FW-017 | 元件使用对齐行列表，呈现状态、名称/型号摘要、封装、类型及关联信息，保留来源的可辨识性。容器缩小时先隐藏封装列，再隐藏类型列；详情仍可读取被隐藏的信息，名称和基本操作保持可达。 |
| FW-018 | 左侧“全部元件”右侧数字徽标必须保留，表示全库已登记符号统计；搜索、筛选后的当前结果数、已选数分别显示并明确口径，不用当前渲染行数替代全库数量。中心页头与状态栏复用同一有效统计来源。 |
| FW-019 | 计数首次未知显示占位符 `…`，真实零显示 `0`。后台 busy、缺字段、坏响应或网络失败保留最后有效数字，说明统计待更新；健康响应恢复后更新。沿用既有状态/心跳模型，不另建计数轮询器。 |
| FW-020 | UUID 是对象选择与定位身份。单选、Ctrl/Cmd 切换、Shift 范围及当前结果全选遵守 ED-020–024；同名对象不合并。选择条显示已选数与当前结果数，提供清除选择和编辑入口，所有入口共用命令可用性。 |
| FW-021 | 用户改变查询、工作空间或页面后，旧读取不得覆盖新意图。提交后刷新只重新读取；通知、选择、定位与成功反馈均归属于对应的唯一刷新执行，清通知不能使旧执行重新获得权限。读取失败保留提交结果并提供只读重试。 |
| FW-022 | 初次加载、空库、无匹配结果、读取失败、保留旧数据的刷新失败分别表达；不能把失败当空结果。空态提供与当前任务相关的下一步，错误包含明确原因和可行的重试/核对入口。 |

## 插件交互与任务反馈

| 编号 | 稳定规则 |
| --- | --- |
| FW-023 | Git 历史沿用提交图与列表联动的风格：节点/父子轨道、refs/HEAD、摘要和左侧详情。图由真实 OID/parents 数据绘制；点击提交查看身份匹配的详情/文件差异，支持父级比较、查询范围、已加载内容查找及有界加载更多。超界和截断明确提示，不能用合成轨道或 ASCII 输出冒充真实 DAG。 |
| FW-024 | Git 普通侧栏往返保留当前页签、筛选、选中提交与滚动位置；切换仓库时隔离仓库状态。状态、历史、详情和文件差异分别管理读取身份与错误，写任务不复用读取结果槽。取消回执与终态分开表示；无在途读取时不显示永久“正在读取”，停止或失败后可就地重试。 |
| FW-025 | LCSC 在左侧完成查号、目标包、符号子库、封装选择、确认、提交结果与继续导入。沿用 LW/IP 的显式选择、操作身份和提交后刷新，不因收窄面板省略确认或隐式选择同名第一项。 |
| FW-026 | 底部任务/问题为通用只读概览，提供任务身份、插件/动作、状态、阶段、时间、错误摘要与有界诊断复制。长错误可展开，复制成功/失败有反馈；不保留完整无限结果，不把关闭面板当作取消任务。 |
| FW-027 | `uncertain` 与原始任务 state 分别保留；界面和复制诊断必须能识别“写入结果不确定/待核对”。超时不能被当作已经确认未写入，核对按相应业务协议执行，不自动重发写操作。取消、撤销、回滚与恢复使用各自术语。 |
| FW-028 | 图标按钮有可访问名称，焦点可见；文本编辑、输入法、弹窗与对象命令遵守 ED。宿主与 Git 随当前中/英文及亮暗主题展示。LCSC 当前中文界面不构成所有插件已完整本地化的承诺；翻译扩展时不得改变业务流程。 |

## 验收要求

下表规定后续改动需要观察的结果，不表示本文件已完成所有环境测试。实现差距必须单列修复，不能以当前缺陷改写上述规则。

| 场景 | 观察结果 | 规则 |
| --- | --- | --- |
| 亮/暗主题，中/英文，长名称/路径 | 层级一致，操作和状态可辨，文本不撑破容器 | FW-001–005、010、028 |
| 1920/1280/960/800/600 宽度，拖动面板与窗口恢复 | 区域职责不变；左抽屉可用，自动收敛不污染保存值 | FW-006–012 |
| Windows 200% 缩放及实际多显示器 DPI | 控件、焦点和内容可达；单纯 CSS 视口模拟不能代替此项 | FW-003、004、010 |
| 首页关闭 → 空态 → 侧栏/按钮重开 → 重载 | 无重复首页；状态按导航语义保留；关闭不改数据和任务 | FW-013–016 |
| 全库计数为未知/0/正数，busy/错误后恢复，旧响应迟到 | 徽标始终有数字或占位；旧值保留、有效新值恢复、口径一致 | FW-018、019 |
| 多选、筛选、同名对象、菜单/快捷键/弹窗 | UUID 与上下文正确；首页未活动时不操作背景对象 | FW-016、020 及 ED |
| 连续提交刷新、通知清除后再次刷新、改搜索/切库 | 迟到旧请求不抢列表、选择或通知；失败重试只读 | FW-021、022 |
| Git/LCSC 左侧往返、窄侧栏、后台任务在途 | 完整流程留在左侧；草稿/任务身份稳定，不因展示切换重复写入 | FW-007、023–025 |
| 取消读取、写入超时/未知、复制失败、长诊断 | 无假加载；不确定结果可见且可复制；反馈与容量有界 | FW-024、026、027 |
| 旧 output/内置插件中心页布局，坏配置与保存失败 | 定向迁移，保留其它有效状态；错误可见，不整份静默重置 | FW-011、012 |
