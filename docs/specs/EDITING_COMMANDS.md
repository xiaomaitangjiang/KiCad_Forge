# 复制、粘贴、剪切、全选、撤销与重做 规格

快照日期：2026-10-20。
同时覆盖**元件对象与文本输入**。本文只定义行为、契约和验收要求，不记录实现进度；逐条支持矩阵见 `docs/AgentDocs/FRONTEND_EDITING_FINAL_2026-10-20.md`。“撤回”统一使用界面术语“撤销”。


## 命令分发与作用范围

| 编号 | 拟定规则 |
| --- | --- |
| ED-001 | 同一命令一次只作用于一个上下文：当前弹窗中的文本编辑 → 当前视图文本编辑 → 当前对象列表。没有有效上下文时禁用；不得同时改文本和对象。 |
| ED-002 | 打开编辑菜单前保存目标与选区；菜单点击可暂时移动焦点，但命令仍作用于原上下文。目标被卸载、弹窗关闭或工作空间切换后不能回落到其它输入框。 |
| ED-003 | 菜单、快捷键、上下文菜单调用同一命令入口，使用一致的可用状态和目标快照；快捷键必须实际实现，不能仅显示标签。 |
| ED-004 | Windows/Linux 使用 Ctrl+C/V/X/A/Z/Y；macOS 使用 Cmd+C/V/X/A/Z，Cmd+Shift+Z 重做；其它重做组合可兼容。纯文本上下文优先浏览器原生快捷键，不再追加一次对象命令。 |
| ED-005 | 输入法组合输入期间不截获这些按键来操作对象；Escape 只关闭当前菜单或取消待剪切标记，不能撤回已提交操作。 |
| ED-006 | 不可用命令禁用并提供原因；执行失败有可见反馈。剪贴板权限失败、内容格式错误、版本不支持、目标不可写分别显示，不以静默 false 结束用户操作。 |

## 文本输入

| 编号 | 拟定规则 |
| --- | --- |
| ED-010 | 复制取得当前文本选区；剪切先确认剪贴板写入成功再删除选区，失败保留原文。密码等敏感输入遵守控件和浏览器限制，不增加绕过能力。 |
| ED-011 | 粘贴替换当前选区或插入光标位置；只接收纯文本，不执行 HTML、脚本或剪贴板携带的命令。空文本不改变字段。 |
| ED-012 | 异步读取剪贴板前捕获目标、选区和编辑版本；返回时复核。读取期间目标卸载、上下文切换、用户改动字段或移动有效选区时中止本次粘贴并提示重试，不写到新焦点。 |
| ED-013 | readOnly 控件允许平台支持的复制/全选，拒绝剪切/粘贴/撤销/重做；disabled 或不支持文本选区的控件不得误判成可编辑。 |
| ED-014 | 全选只选择当前字段全部文本，不改变列表选择、查询范围或提交表单。没有字符时安全无操作。 |
| ED-015 | 撤销/重做只操作该文本编辑器的本地编辑历史，保持 React 控件值与 DOM 一致；不会撤销库导入、删除、绑定或其它字段。失焦和菜单操作不能丢失本次选区。 |
| ED-016 | 文本命令复用平台/浏览器编辑能力及现有 React 状态更新，不引入完整富文本编辑器来实现普通输入框功能。原生编辑的支持范围必须在真实 WebView2 验证。 |

## 对象选择与全选

| 编号 | 拟定规则 |
| --- | --- |
| ED-020 | 对象按 UUID 维护选择集合，当前详情对象与多选集合分别表达。单击替换集合，Ctrl/Cmd+单击切换该项，Shift+单击选择当前排序中锚点到目标的连续范围。 |
| ED-021 | 列表全选作用于当前搜索、筛选、工作空间和排序下已经加载的结果集；含滚动视口外已加载对象，不只选可见 DOM，也不默认选择数据库中未加载的所有对象。若以后分页，跨页全选另设明确入口与计数。 |
| ED-022 | 查询或工作空间切换清除该列表选择及范围锚点；同一结果集刷新剔除已消失 UUID。相同名称不能合并选择或替换身份。 |
| ED-023 | 文本字段有焦点时 Ctrl/Cmd+A 只选文本；对象列表有焦点时才执行业务全选。侧栏“全部”继续保持查询语义，不能绑定为本命令。 |
| ED-024 | 混合对象类型不隐式转换。首个实现需明确支持的列表类型；某类封装/3D 列表尚无写能力时，对应命令禁用并说明，不能把“六命令有菜单”写成所有对象类型已支持。 |

## 对象复制与粘贴

| 编号 | 拟定规则 |
| --- | --- |
| ED-030 | 对象复制不改数据库、源文件、锁或类型；可以从可读取的锁定/官方库复制。复制完整可恢复的对象内容和必要元数据，不能只复制列表摘要再重建一个丢失图形/引脚的符号。 |
| ED-031 | 对象剪贴板使用带格式版本和对象种类的结构化数据，并可提供纯文本摘要。粘贴前校验内容、数量、版本和大小；剪贴板内容不拥有写入授权，不能携带任意宿主执行命令或任意目标路径。 |
| ED-032 | 粘贴前明确目标包和实际子库/目录；目标必须登记、启用、可写，且类型与路径角色一致。使用 [导入协议](IMPORT_PROTOCOL.md) 的 UUID、相对路径、锁/保护、根目录归属和提交前复核规则。 |
| ED-033 | 复制产生独立目标对象身份，不冒用源 UUID。同名冲突须要求用户明确重命名、选择其它目标或取消；默认不覆盖。同一确认意图网络重试不能产生重复对象，用户再次明确粘贴则是新意图。 |
| ED-034 | 不把名称或内容 KF 标识当作数据库对象 UUID。KF 字段、派生符号和多单元符号按现有格式完整保留并校验；身份冲突策略须先测试，不能重写几项属性后丢失其它节点。 |
| ED-035 | 符号引用的封装/3D 不默认复制整个依赖库。目标能唯一解析且文件有效时可保留引用；不可解析或有歧义时明确要求映射、补充依赖或取消。不得默默绑定同名第一项。 |
| ED-036 | 粘贴提交复用宿主文件 mutation 和数据库 session；成功后刷新、定位目标并选中新对象。刷新失败保留提交结果，只重试读取；不得再次粘贴来刷新。 |

## 剪切与移动

| 编号 | 拟定规则 |
| --- | --- |
| ED-040 | 剪切仅记录待移动意图并显示标记，不立即删除文件/行。源不可写时剪切禁用，复制仍可用。取消、Escape、替换剪贴板或结束会话均只清除标记。 |
| ED-041 | 真正删除源对象只能在目标写入与源移除能够作为同一受控逻辑操作提交时发生；任一文件/数据库步骤失败则不留下“源已删而目标缺失”的结果。多文件崩溃恢复必须独立验收。 |
| ED-042 | 移动前重新核对源 UUID、内容版本、源/目标 owner 与锁。剪切后源被外部编辑、删除或锁定时，拒绝移动，不将旧快照写回源。 |
| ED-043 | 移动保留对象逻辑身份并更新归属及引用；复制使用新身份。跨库移动所需引用无法保持有效时先提示并阻止提交，不悄悄降级成复制后删行。 |
| ED-044 | 源与目标为同一对象位置时返回可解释的无变化结果，不生成重复对象或删除源。完成移动后剪切意图消费一次；重复回包或重试不能再次删除。 |
| ED-045 | 只信任当前应用会话内创建、仍有效的剪切意图。外部程序、旧版本或前一会话的剪贴板内容不得触发源删除；最多按可验证复制内容处理。 |

## 撤销与重做

| 编号 | 拟定规则 |
| --- | --- |
| ED-050 | 对象编辑使用应用会话内的成功操作历史；复制、全选、查找、失败尝试及无变化结果不进入历史。关闭/重启后历史是否持久化不作首期保证，启动恢复日志继续独立工作。 |
| ED-051 | 一次成功粘贴/移动作为一个历史单元；批量操作只有全部副作用均被记录并可逆时才能作为同一单元。不能用多次“删除行”模拟撤销一次跨库移动。 |
| ED-052 | 撤销执行已提交变更的逆操作，重做执行同一确认内容；两者都再次复核授权、对象版本和文件摘要。目标已被外部修改、被其它关系引用或被锁定时整体拒绝并说明，不覆盖新内容。 |
| ED-053 | 撤销或重做失败时历史指针不前移，不跳过该条悄悄处理更早记录；不得为了恢复而生成新对象 UUID。 |
| ED-054 | 撤销后发生新的成功编辑，清空重做分支；单纯选择、复制、查询、刷新和失败尝试不清空。进行中的持久写操作禁用相冲突的撤销/重做，防止乱序执行。 |
| ED-055 | 导入取消、数据库回滚、mutation 启动恢复都不构成用户撤销。要支持“撤销导入”，必须记录该次实际提交增量和原状态，并逐项校验后再开放；普通目录导入部分提交不能声称天然可整次撤销。 |
| ED-056 | 撤销导入不得删除原本存在的复用封装、其它操作后来追加的符号或整个目标库。尚不能可靠恢复的导入必须明确标为不可撤销，菜单不能误导；重做在线导入也不能重新下载不同版本后冒充原操作。 |

## 对象编辑契约

以下契约用于 ED-030..056 的跨进程边界、持久化格式和容量行为；修改字段、版本或数值时必须同时更新本规格和测试。

### 剪贴板格式

- 系统剪贴板只写 UTF-8 纯文本：首行 `KFORGE-SYMBOLS-V1`，其后是 JSON envelope。读取时首行接受 LF 或 CRLF；首行之后的内容按原样解析，不因平台换行规范做全局替换。
- envelope 字段固定为 `app`（`KiCad_Forge`）、`kind`（`kforge.symbols`）、`version`（`1`）、`created_at`（ISO-8601）、`summary`、`items`。
- 每个 item 字段为 `uuid`、`kf_id`、`name`、`library_id`、`library_name`、`source_path`、`source_digest`、`dependency`、`sexpr`。`sexpr` 是完整顶层节点原文；`dependency:true` 的父节点排在子节点之前。
- `uuid`、`source_path`、`source_digest` 只描述来源，不授予目标写权限；payload 不携带宿主命令、任意目标绝对路径或可执行内容。
- 无首行标识时按普通文本处理；标识后 JSON 解析失败、`kind`/`version` 不符、`items` 为空或结构非法时按格式失败，不得猜测修复。
- 改名必须同时处理顶层名、内部单元名和相关 `extends`，不能对整个节点做字符串替换。

### 宿主接口

对象导出和写入由宿主完成，前端不得直接写 `.kicad_sym` 或数据库。接口前缀为 `/api/editing`，请求和响应均为 JSON；失败响应为 `{"ok":false,"code":"...","error":"..."}`。

| 端点 | 语义 |
| --- | --- |
| `POST /export` | 按 UUID 读取完整顶层节点和必要父节点；只读，不写 DB/文件；1..200 个 id。 |
| `POST /paste` | `dry_run` 校验目标、冲突、依赖和容量；提交生成新 UUID/KF，一次写入文件与 DB；`operation_id` 幂等。 |
| `POST /cut` | 建立当前会话的一次性待移动意图，返回完整节点和 token；不删源、不写文件。 |
| `POST /cut/clear` | 清除一个待移动 token；重复清除安全无操作。 |
| `POST /move` | `dry_run` 返回移动计划；提交把目标追加、源移除和 DB 归属更新放入同一次受控提交；保留 UUID/KF；源与目标为同一文件或同一位置时为 noop。 |
| `GET /history` | 返回可撤销/重做状态和有限摘要，不返回文件快照。 |
| `POST /history/undo`、`/history/redo` | 整体撤销或重做最近一个单元；冲突时整体拒绝。 |

`paste`/`move` 的 `dry_run` 必须返回目标摘要和冲突清单，提交时再次校验该摘要；目标在预检后被改动时返回 `source_changed`，不能按旧计划写入。提交单元由一次 `SourceMutationService::apply` 及同一数据库 session 组成，不能拆成前端可见的中间态。

`operation_id` 标识一次确认意图：同 id 且同内容摘要重放首次结果，同 id 不同摘要拒绝为 `operation_conflict`；缓存最多 64 条、仅进程内有效。`undo`/`redo` 不接收 `operation_id`，请求结果不确定时应先读取历史对账，不能自动重试。

错误码至少覆盖：`invalid_request`、`target_not_found`/`symbol_not_found`、`target_not_writable`、`payload_too_large`、`symbol_invalid`、`conflict`、`source_changed`、`operation_conflict`、`invalid_token`、`commit_failed`，以及历史的 `history_empty`、`history_conflict`、`history_full`、`history_failed`。HTTP 状态需稳定映射：404 未找到、403 不可写、400 请求非法、413 超限、409 冲突/失效、422 内容非法、500 提交失败。

### 容量与会话边界

| 资源 | 上限或生命周期 |
| --- | --- |
| 对象剪贴板 | 1..200 项；序列化后 UTF-8 总计 ≤ 4 MiB（含首行标识和 JSON）；超限整次拒绝，不截断。 |
| 导出/粘贴 | 单次 id 或 items ≤ 200；粘贴请求体 ≤ 4 MiB。 |
| 待移动意图 | 最多 16 个；每个一次性有效 30 分钟；新意图按插入序淘汰旧意图；进程重启失效。 |
| 幂等缓存 | 最多 64 个 `operation_id`；仅进程内。 |
| 会话历史 | 最多 20 个单元、总计 32 MiB；单个文件的前后内容快照各 ≤ 16 MiB；超单次预算或单文件预算时整次拒绝。 |
| 历史生命周期 | 仅当前宿主进程有效；重启后清空。前端重载若宿主会话仍在，历史可继续使用；多实例不共享。 |

历史容量必须在文件/DB 提交前预留；不能先提交成功再发现历史无法记录。超总预算时按最旧单元整条淘汰；单次操作本身超预算时返回 `history_full` 且不写源/目标文件。历史单元必须包含涉及文件的前后内容和必要的 DB 前后状态；撤销/重做时任何文件摘要或行状态不符即整体拒绝，指针不前移。

### 首期实现范围

- 对象命令只作用于首页符号列表；封装、3D 和插件自定义对象没有独立编辑列表时不宣称支持对象编辑，其文本字段仍按文本上下文处理。
- 现有导入、删除、绑定、类型管理、Git 等写操作不进入本历史；首期历史只覆盖符号粘贴和跨库移动。
- 派生符号的父节点必须在同一 `.kicad_sym` 文件内；跨文件 `extends` 不支持。移动不向目标节点补写 KF，KF 仍作为数据库行指纹。
- 首期不做封装/3D 对象复制；引用缺失或歧义时至少给出警告，不复制整个封装/3D 库，也不默认绑定同名第一项。完整的映射/补充依赖流程仍是 ED-035 的待实现要求。

## 资源约束

复用现有平台剪贴板、React、SDK 模型、任务客户端与 SourceMutationService；不新增常驻扫描器、不轮询剪贴板、不缓存全库对象。复制/历史数据按实际选中对象领取，操作结束释放订阅与在途读取。

选择集合只保存 UUID；完整对象在复制、粘贴、撤销/重做时按需读取并及时释放。全选集合可以超过剪贴板项数：超限时拒绝复制或粘贴并说明，不自动截成前 N 项；批量中任一对象失败时整批拒绝，不部分移动、不静默丢备份。

## 验收矩阵

| 场景 | 必须观察的结果 | 规则 |
| --- | --- | --- |
| 搜索框文本选区 → 点编辑菜单复制/剪切 | 保留正确选区，只改该字段，不触发对象命令 | ED-001、002、010 |
| input/textarea/contentEditable、只读、禁用、密码 | 可用状态符合控件限制；失败可见、原文保留 | ED-006、013 |
| 粘贴等待期间关弹窗、换库、移光标或继续输入 | 返回后不写入旧目标/新焦点，提示重新操作 | ED-012 |
| 中文输入法、Unicode、换行、空剪贴板 | 不截断组合输入，不执行对象快捷键，纯文本结果正确 | ED-005、011 |
| 文本撤销/重做及 React 重绘 | 字段值与 DOM 一致，不改变对象历史 | ED-015 |
| 多选、Shift 范围、筛选后全选、空列表 | UUID 集合和计数正确；不误选隐藏筛选项/未加载项 | ED-020–024 |
| 同名不同来源复制、相同目标重复确认 | 不冒用 UUID，不覆盖；同意图重试幂等，新意图明确 | ED-030–034 |
| 依赖封装缺失或同名歧义 | 提示映射或中止，无默认错误绑定 | ED-035 |
| 剪切后取消/换剪贴板/源被改动或锁定 | 源文件和行未删除；过期意图不能移动 | ED-040、042、045 |
| 跨库移动在目标写、源移除、SQL COMMIT、进程中断处失败 | 源/目标/关系一致或进入明确恢复冲突；不丢源 | ED-041、043 |
| 成功移动重试，粘贴后刷新失败 | 一次提交、一次消费；只重新读取 | ED-036、044 |
| 撤销 → 新编辑 → 重做 | 新分支清重做；失败/查询不清历史 | ED-050、054 |
| 撤销/重做时外部修改、库锁定、引用新增 | 不覆盖、不删共享对象，历史指针保持 | ED-052、053 |
| 导入复用封装后尝试撤销 | 未支持时明确禁用；支持后也不删除复用对象和其它新增内容 | ED-055、056 |
