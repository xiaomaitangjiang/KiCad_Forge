# 注意事项

简体中文 ~ [English](usage-notes.en.md)

## 插件系统

1. 插件以独立 Python 进程运行，拥有与主程序相同的文件系统访问权限，**Kicad_Forge无法提供任何安全保证**。请仅安装来自可信来源的插件，恶意插件可能读取、篡改或删除任意文件
2. 插件**不应该**依赖软件自身或API自带的任何副作用以实现某种功能，以此方式实现的插件开发者不保证其的向后兼容性

## 关于项目

1. 由于开发者学艺不精，在整个开发过程中大量使用了AI生成的代码，对于出现的任何BUG给您带来的不便与困扰，我在此表达诚挚的歉意
2. 对于出现的任何BUG，请麻烦提交Issue并附赠上详细的BUG描述和软件的Log文件以方便开发者复现BUG，如果可以的话可以参考[CONTRIBUTING.md](../../CONTRIBUTING.md)提交PR，为这个项目贡献代码，谢谢
3. 请**不要**提交“许愿式Issue”,例如：

> “软件有bug”
>
> “怎么软件加载不出东西啊”
>
> “为什么我下载不了安装包”
>
> “为什么不适配鸿蒙”
