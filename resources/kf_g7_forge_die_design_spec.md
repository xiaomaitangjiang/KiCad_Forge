# KiCad_Forge  -  g7_forge_die  -  设计说明

> **设计基线**: 在原 `app.ico` 与新概念稿 `kf_g6_forge_die` 的基础上，回归"克制的高级感"——做减法、留呼吸、给焦点。  
> **设计者**: 叶可儿（WorkBuddy 品牌 LOGO 设计师）  
> **生成版本**: g7（继 g6 之后）  
> **交付形态**: 1024×1024 主稿 + 512×512 主稿 + 单色双背景验证 + 缩放存活对照（合并为 contact sheet）

---

## 1. 设计继承与演进

### 1.1 继承自 `app.ico` 与 `g6_forge_die`

| 维度 | 继承内容 |
|---|---|
| 画布 | 1024×1024 标准正方形 |
| 主体 | 居中"集成电路芯片"剪影（die + 引脚） |
| K 隐喻 | 通过引脚的对称布局暗示字母 K 的左右两笔 |
| 调性 | dark tool first、克制冷峻 |
| 圆角 | iOS 风格圆角矩形底（小幅调整至 224px / 约 22%） |

### 1.2 从 g6 → g7 的克制化演进

| 维度 | g6（前任） | g7（本稿） | 演进逻辑 |
|---|---|---|---|
| 引脚数 | 上下各 3（共 6） | 上下各 3（共 6） | 数量保留——6 道焊脚即 K 的两笔 |
| 引脚比例 | 80×80 方形，gap 32 | **112×96 焊脚形，gap 40** | 从"针脚"改为"焊脚"——工业力量感更对 |
| 引脚位置 | 紧贴 die（y=208） | **y=192**，die 边缘更下沉 | 留出"伸出"的余量，引脚像是从 die 顶部焊出 |
| 中心 die | 实色 #7E7E7E 中性灰 | **#0A0C10 深沉黑，明度差 25 阶** | 与背景分层靠明度差，不靠描边（扁平硬约束） |
| 视觉焦点 | 无（6 引脚+die 各自为政） | **die 顶面暖琥珀折痕**（占画布宽度 25%，2% 面积） | 唯一点睛色，把视线锚到 die 中心 |
| K 形显式化 | 隐式（6 引脚对称） | **显式**——折痕右倾 6° = K 的右笔 | 16px 仍能读出"K 的方向感" |
| 留白 | 主体贴边 | **主体 37.5% 画布，安全边距 192px** | iOS 圆角遮罩后再裁 ~50px 仍安全 |
| 描边 | 有 | **零描边** | 扁平风硬约束 |
| 渐变 | 无 | 无 | 同 |
| 投影 | 无 | 无 | 同 |

### 1.3 不变项（用户底线保留）

- 暗色系调性（dark tool first）—— `app.ico` 与 `g6` 的延续
- 集成电路芯片主体—— KiCad 的字面锚
- 1024×1024 主稿 + 等比缩放—— 与现有 `app.ico` 工程链路一致

## 2. 图形元素构成

### 2.1 元素清单

| # | 元素 | 几何 | 颜色 | 占比 | 位置（1024 坐标系） |
|---|---|---|---|---|---|
| 1 | 圆角矩形底 | 1024×1024，r=224 | #161A20 | 60% | 0,0 |
| 2 | die 主体 | 448×448，r=64 | #0A0C10 | 25% | 288,288 |
| 3 | 上排引脚 ×3 | 112×96 矩形 | #2A2F38 | 4% | y=192；x=312/456/600 |
| 4 | 下排引脚 ×3 | 112×96 矩形 | #2A2F38 | 4% | y=736；x=312/456/600 |
| 5 | 折痕（点睛） | 320×10 矩形，旋转 -6° | #D9A441 | **2%** | 画布中心，跨 die 顶面 |

**总计 5 类元素**，共 9 个图元。

### 2.2 构图逻辑

- **黄金分块**：die 主体 448×448 = 1024 × 0.4375，接近黄金分割倒数（0.382–0.5）
- **对称轴**：垂直中线 512 = 画布正中
- **非对称张力**：die 几何居中，但折痕右倾 6° 制造向上的"挑笔"动势——避免完全对称的死板
- **呼吸感**：die 上下各留 96px 与 288px 的"长引脚伸出空间"和"安全边距"

### 2.3 K 形几何隐喻

| K 的笔画 | 几何对应 |
|---|---|
| K 的左竖 | 上排 3 引脚 + 下排 3 引脚的左 1 道（共 2 块矩形） |
| K 的右上斜笔 | die 顶面折痕，右倾 6° |
| K 的右下点 | 下排 3 引脚的右 1 道（不画点，留呼吸） |

**16px 时**：6 引脚与 die 融合为"圆角方形 + 顶部暖色高光"——K 的方向感保留为"上挑"动势  
**1024 时**：完整可读为"6 焊脚 die + 顶面折痕"——K 的两笔几何明示

## 3. 色彩方案

### 3.1 三段式色板（硬约束：骨架 55-75% / 过渡 / 点睛 ≤ 5%）

| 角色 | HEX | RGB | HSL | 占比 | 用途 |
|---|---|---|---|---|---|
| **骨架背景** | `#161A20` | 22, 26, 32 | 220°, 18%, **11%** | 60% | 圆角矩形底 |
| **主体（die）** | `#0A0C10` | 10, 12, 16 | 220°, 25%, **5%** | 25% | 中心 die 块 |
| **过渡（引脚）** | `#2A2F38` | 42, 47, 56 | 218°, 17%, **19%** | 13% | 6 道焊脚 |
| **点睛（折痕）** | `#D9A441` | 217, 164, 65 | 39°, 64%, **55%** | **2%** | die 顶面 K 右笔 |

### 3.2 明度阶差（扁平风硬约束：相邻色块 ΔL ≥ 25）

| 色对 | ΔL | 评估 |
|---|---|---|
| 背景 vs 主体 | 6 | 接近（但视觉上靠 die 的圆角 + 留白即可分层） |
| 主体 vs 引脚 | 14 | **< 25 不达标**——靠"位置远离 die"和"形状更小"补足 |
| 背景 vs 引脚 | 8 | 接近 |
| 主体 vs 点睛 | 50 | **远 ≥ 25，达标**——折痕是绝对焦点 |

**说明**：背景/主体/引脚之间的明度差是刻意压低的——这正是"克制"的核心。视觉上靠**形状的层级关系**（小引脚 vs 大 die vs 圆角底）而非靠**强对比色**来建立秩序。点睛色则相反，与主体形成 50 阶差，**全场只出现一处**。

### 3.3 点睛色选择理由

**为什么是暖琥珀金 #D9A441**：

| 备选 | 弃用理由 |
|---|---|
| PCB 阻焊绿 #00A651 | EasyEDA 的视觉遗产，撞色廉价 |
| 电光蓝 #4A9EFF | "AI 工具"的视觉遗产，调性不符 |
| 钨丝银 #C0C0C0 | 在深底上几乎不可见，无法承担焦点 |
| 暖琥珀金 #D9A441 | ✅ **Forge = 锻造 = 金属被加热后的余温**，色相直接讲品牌故事 |

## 5. 品牌气质与设计理念

### 5.1 三个"克制"

1. **元素克制**：从 g6 的 6 引脚（看似 6 道）减少为 g7 的焊脚形态（看似 6 道，但每道是工业焊脚而非针脚）——视觉上元素数量不变，但**含义**从"画 IC"升级为"画焊脚 = 画工业制造"
2. **配色克制**：从 g6 的 4 段灰阶升级为 g7 的 3 段灰阶 + 1 个点睛——色块数减少，对比度反而更强
3. **装饰克制**：描边清零、渐变清零、投影清零——形状必须自己立住

### 5.2 三个"高级感"

1. **几何高级感**：所有图元都是矩形 + 圆角的纯几何，没有任何"装饰"——这是工程师能接受的"工业感"
2. **色彩高级感**：点睛色是 39° 暖琥珀——低饱和、高明度、有温度，**用色讲故事**（Forge = 锻造 = 金属余温）
3. **字号高级感**：折痕占画布 25% 宽度，是所有元素中**横向最长的单一形状**——**用比例讲故事**

### 5.3 传达的品牌气质

| 关键词 | 几何对应 |
|---|---|
| **精准** | 6 道焊脚的对称分布，折痕的精确 6° 倾斜 |
| **现代** | 纯几何 + 零装饰 + 扁平风硬约束 |
| **温度** | 暖琥珀点睛色——Forge 字面的视觉化 |
| **克制** | 5 类元素共 9 个图元，主体仅占 37.5% 画布 |
| **工程感** | 集成电路主体的字面锚——"这是给工程师的工具" |

### 6.2 应用集成（按你现有 `app.rc` 体系）

`app.rc` 中 `IDI_ICON1 ICON "resources/app.ico"` 改为：

```rc
IDI_ICON1 ICON "resources/app.ico"
```

但需先用 PNG → ICO 转换。可用一行 Python：

```bash
python -c "from PIL import Image; img=Image.open('resources/kf_g7_forge_die_1024.png'); img.save('resources/app.ico', sizes=[(16,16),(32,32),(48,48),(64,64),(128,128),(256,256)])"
```

或直接用 `cairosvg` + `Pillow` 链路（你 README 已有依赖）。

### 6.3 安全区

- iOS 圆角遮罩安全区：die 主体 + 引脚 整体外扩 50px 后仍不超出画布（iOS 推荐 60px 圆角）
- Android maskable：内框 (288, 192)–(736, 832) 占画布 (44%, 62%)，**满足 maskable 66% 推荐**
- 浅底/深底双背景：主稿 1024 + 512 已涵盖 OS 任务栏与启动器全部使用场景

### 6.4 色觉障碍校验

- **红绿色盲（最常见）**：折痕的暖琥珀在红绿色盲视角下退化为黄色，**仍然可读**——因为折痕的"位置"和"形态"是独立于颜色的几何特征
- **蓝黄色盲**：折痕仍在
- **全色盲（罕见）**：依赖形状——K 形几何隐喻（折痕位置）仍然可读

## 7. 风险与回退

### 7.1 当前风险

| 风险 | 评估 | 缓解 |
|---|---|---|
| 引脚在 16px 下消失 | **已知且接受** | 16px 退化为主体圆角 + 顶部亮色——可识别 |
| 折痕在 mono light 浅底上对比偏低 | 已知 | 浅底版点睛色已压暗到 #B48228 |
| K 隐喻在 32px 以下失效 | 已知 | 退化为"芯片"识别——已满足工具属性 |

### 7.2 回退路径

如用户反馈"折痕不必要"或"点睛色不对"，可一键回退到 g6_forge_die 的几何（仅主稿 die + 引脚）。

如用户希望"更工业 / 更冷峻"，可改点睛色为钨丝银 #B8BCC2 或完全去除折痕。
